# pds Language

This is a unique and minimalistic programming language created entirely in **JavaScript**. It features a syntax that feels more like writing natural sentences or paragraphs — no parentheses `()`, no curly braces `{}`, no colons `:`, and no indentation rules!

## Why I Built It

While learning **Next.js** and **TypeScript**, I became curious about how programming languages actually work. That curiosity turned into a passion project — and this language is the result.

My goal was to create a simple, readable syntax that can be understood even by beginners, while still being powerful enough to express logic and computation.

## Features

- **Human-friendly syntax**: No boilerplate or strict structure.
- **Interpreter built with JavaScript**.
- **Clean and minimal code** style.
- **Easy to extend** and experiment with.
